# رِوَاق — مدارسة العلوم الشرعية

## تشغيل المشروع

1. ثبّت Python 3.11 أو أحدث.
2. ثبّت المتطلبات: `pip install -r requirements.txt`
3. انسخ `.env.example` إلى `.env` محليًا، واملأ القيم السرية الجديدة. لا يتضمن هذا الملف المضغوط ملف `.env` حفاظًا على مفاتيحك السرية. التطبيق يقرأ الملف محليًا عبر `python-dotenv`. لا ترفع ملف `.env` إلى Git أو تشاركه.
4. شغّل محليًا: `python app.py`.

## متغيرات الاستضافة المطلوبة

- `SECRET_KEY`: مفتاح عشوائي طويل لتوقيع الجلسات.
- `UPSTASH_REDIS_REST_URL` و`UPSTASH_REDIS_REST_TOKEN`: بيانات Upstash الجديدة. دونها لن تُحفظ البيانات بشكل دائم.
- `ADMIN_PASSWORD`: كلمة مرور لوحة الإدارة الجديدة.
- `ONESIGNAL_APP_ID` و`ONESIGNAL_REST_API_KEY`: اختياريان للإشعارات.
- `SESSION_COOKIE_SECURE=true` عند استخدام HTTPS.

## إجراء أمني مهم قبل النشر

النسخة الأصلية المرفوعة تضمنت بيانات اتصال ومفتاح إشعارات داخل الكود. احذف/دوّر تلك القيم من لوحات الخدمات وأنشئ بدائل جديدة، ثم ضع البدائل في Environment Variables على Vercel أو مزود الاستضافة. لا تستخدم القيم القديمة حتى لو أزيلت من الملفات.

## كلمات المرور الحالية

كلمات المرور الجديدة تُحفظ باستخدام تجزئة آمنة. عند أول تسجيل دخول صحيح لحساب قديم، تُحوّل كلمة مروره تلقائيًا من النص القديم إلى تجزئة. يُنصح بأخذ نسخة احتياطية آمنة من بيانات Redis قبل النشر.

## ملاحظات

- ملفات الرفع المحلية قد لا تكون دائمة على الاستضافات عديمة الحالة مثل Vercel؛ استخدم تخزين ملفات دائمًا عند الاعتماد على رفع ملفات المستخدمين.
- لا يحتوي الأرشيف الأصلي على مجلد `static` أو ملف `logo.png` رغم أن بعض الصفحات تشير إليه؛ أضف الأصول المطلوبة إذا كان الشعار مفقودًا في النشر.


## تشغيل محلي على Windows

انقر مرتين على الملف `تشغيل-رواق-محلي.bat`. سيحاول تثبيت المكتبات المطلوبة ثم تشغيل الموقع. افتح `http://127.0.0.1:5000`. يلزم إعداد بيانات Upstash Redis في ملف `.env` حتى تُحفظ البيانات بين مرات التشغيل؛ لا تضع مفاتيحك السرية في ملفات عامة أو تشاركها.


## التشغيل المحلي بدون إعداد Redis
إذا لم تضف متغيرات `UPSTASH_REDIS_REST_URL` و`UPSTASH_REDIS_REST_TOKEN`، سيحفظ التشغيل المحلي بيانات الحسابات والمحتوى في `data/rewaq_data.json` داخل مجلد المشروع. احتفظ بهذا الملف ولا تشاركه لأنه يحتوي بيانات المنصة. الحسابات الموجودة في قاعدة Redis السحابية لن تظهر محليًا إلا بعد ضبط بيانات اتصال Redis الصحيحة.
